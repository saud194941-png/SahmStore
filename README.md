# متجر سهم (Sahm Store)

منصة ويب تفاعلية تحاكي إدارة متجر حقيقي بطريقة ممتعة وتعليمية باستخدام الذكاء الاصطناعي.

## المميزات
- محاكاة اقتصادية كاملة للمبيعات والمخزون.
- إدارة الموظفين، ودفع الرواتب.
- التوسع العقاري وشراء الفروع.
- نظام القروض البنكية والفوائد.
- الذكاء الاصطناعي التفاعلي المربوط بـ Gemini.
- مخططات بيانية تفاعلية.

## تعليمات الرفع والاستضافة (Deployment)

أسهل وأفضل طريقة لرفع هذا المشروع هي باستخدام **Vercel** لأنها المنصة الأم لإطار عمل Next.js.

### الخطوات لرفعه على Vercel:
1. قم برفع مجلد المشروع هذا إلى مستودع (Repository) في حسابك على **GitHub**.
2. اذهب إلى موقع [Vercel.com](https://vercel.com) وقم بتسجيل الدخول باستخدام GitHub.
3. اضغط على `Add New` ثم `Project`.
4. قم باستيراد (Import) المستودع الذي للتو قمت برفعه.
5. **مهم جداً: المتغيرات البيئية (Environment Variables)**
   - في صفحة إعدادات الرفع في Vercel، افتح قسم `Environment Variables`.
   - قم بإضافة المتغير التالي:
     - Name: `GEMINI_API_KEY`
     - Value: `مفتاح הـ API الخاص بك من جوجل`
6. اضغط على `Deploy` وانتظر بضع دقائق.
7. مبروك! 🎉 ستحصل على رابط مباشر لمشاركة اللعبة مع العالم.

*ملاحظة: اللعبة تحفظ تقدم اللاعب محلياً في المتصفح (Local Storage)، لذلك لن يفقد أي لاعب رصيده عند تحديث الصفحة.*
